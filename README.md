# NASA Airfoil Self-Noise Prediction — ML-2026

**Course:** Machine Learning Project

## Project Overview

This project builds a supervised tabular regression pipeline on the **NASA Airfoil Self-Noise** dataset (UCI / Brooks, Pope, & Marcolini, 1989) to predict the **Scaled Sound Pressure Level (dB)** generated by a NACA 0012 airfoil in wind-tunnel tests.

- **Dataset:** `data/airfoil_self_noise.dat` (1,503 instances, 5 continuous features, 0 missing values)
- **Features:** `frequency` (Hz), `angle_of_attack` (°), `chord_length` (m), `free_stream_velocity` (m/s), `suction_side_displacement_thickness` (m)
- **Target:** `scaled_sound_pressure_level` (dB)
- **Key Guardrail:** Group-aware validation (`GroupKFold` / `GroupShuffleSplit` by aerodynamic configuration) alongside standard CV to prevent frequency-sweep data leakage, with all preprocessing encapsulated in `scikit-learn` `Pipeline`s.
